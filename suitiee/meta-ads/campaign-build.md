# سويتي: مواصفات بناء حملات ميتا (Meta Ads)

> هذا الملف مكتوب عشان تنفّذه جلسة Claude Code على جهازك (اللي فيها Meta Ads MCP). الملف المرافق `campaigns.json` فيه نفس الإعدادات بصيغة جاهزة للتنفيذ.
> الخطة الكاملة: https://claude.ai/artifact/FK16LZrqktT4uzRGYwDzU3

---

## ٠. قواعد التنفيذ (غير قابلة للتفاوض)

1. **كل شي ينبني بحالة PAUSED (موقوف).** ولا ريال يُصرف بدون موافقة صريحة من خالد بنفس الجلسة: "شغّلها".
2. **حد صرف للحساب:** ٦٬٠٠٠ ريال (Account spending limit). وحد صرف لكل حملة (Campaign spend cap) حسب الجدول تحت.
3. قبل أي إنشاء: اعرض ملخص (اسم الحملة، الميزانية، الجمهور، الإعلانات) وانتظر الموافقة.
4. لا تنشئ ولا تعدّل شي خارج حساب سويتي الإعلاني.
5. أي رقم في نص الإعلان لازم يطابق "ورقة الأرقام" في الخطة. إذا الخانة فاضية، لا تنشر النص.

## ٢. تسمية موحدة

```
حملة:     SUIT | {المرحلة} | {الهدف} | {YYMM}
مجموعة:   SUIT | {المرحلة} | {الجمهور} | V{رقم الفيديو}
إعلان:    V{رقم الفيديو} | H{A/B/C} | {الكلمة}
```

أمثلة: `SUIT | TEST | CTWA | 2610` · `SUIT | TEST | Riyadh-Broad | V1` · `V1 | HB | حجز`

الكلمة في اسم الإعلان تربطه بالكلمة العضوية، فنعرف أي فيديو جاب كل عميل.

## ٣. الحملات

### الحملة ١: اختبار الإعلانات (المرحلة ٢، الأيام ١٠–٢٠)

| الإعداد | القيمة |
|---|---|
| الاسم | `SUIT \| TEST \| CTWA \| 2610` |
| الهدف | **Leads** (العملاء المحتملون) |
| مكان التحويل | **Messaging ← WhatsApp** (Click-to-WhatsApp) |
| هدف الأداء | Maximize conversations (أكثر محادثات) |
| الميزانية | على مستوى المجموعة (ABO)، **٦٥ ريال/يوم لكل مجموعة** × ٣ مجموعات × ١٠ أيام ≈ **١٬٩٥٠ ريال** |
| حد صرف الحملة | ٢٬٠٠٠ ريال |
| المجموعات | ٣، وحدة لكل فيديو من أفضل ٣ فيديوهات عضوية بالأسبوعين الأولين |
| الإعلانات | ٣ لكل مجموعة (الهوك A و B و C) = **٩ إعلانات** |

**API mapping (للجلسة المحلية):** `objective: OUTCOME_LEADS`, ad set `destination_type: WHATSAPP`, `optimization_goal: CONVERSATIONS`, `billing_event: IMPRESSIONS`, `bid_strategy: LOWEST_COST_WITHOUT_CAP`, `status: PAUSED`. تحقق من القيم المسموحة بالنسخة الحالية من الـ API قبل الإنشاء.

### الحملة ٢: التوسع (المرحلة ٣، الأيام ١٨–٣٠)

| الإعداد | القيمة |
|---|---|
| الاسم | `SUIT \| SCALE \| CTWA \| 2610` |
| الهدف | نفس الحملة ١ |
| الميزانية | على مستوى الحملة (Advantage campaign budget)، **٢٩٠ ريال/يوم** × ١٢ يوم ≈ **٣٬٥٠٠ ريال** |
| حد صرف الحملة | ٣٬٥٠٠ ريال |
| الإعلانات | **أفضل إعلانين** من الحملة ١ حسب تكلفة المالك المؤهل. استخدم **نفس رقم المنشور (Post ID)** عشان تبقى اللايكات والتعليقات |
| الزيادة | +٢٠٪ كل ٤٨ ساعة إذا التكلفة ضمن الهدف ٣ أيام |

### الحملة ٣: إعادة الاستهداف (المرحلة ٤، الأيام ١٨–٣٠)

| الإعداد | القيمة |
|---|---|
| الاسم | `SUIT \| RT \| CTWA \| 2610` |
| الميزانية | **٤٠ ريال/يوم** × ١٢ يوم ≈ **٥٠٠ ريال** |
| الجمهور | `RT-Video50-30d` + `RT-IG-Engaged-30d` ناقص `EX-Leads-60d` |
| الإعلانات | فيديو ١٠ (تجربة مالك) + فيديو ٩ (٣ أرقام / التقرير) |
| تنبيه | إذا التكرار (Frequency) فوق ٣، بدّل الفيديو |

**المجموع:** ~١٬٩٥٠ + ٣٬٥٠٠ + ٥٠٠ = **~٥٬٩٥٠ ريال** (تحت حد الحساب ٦٬٠٠٠).

## ٥. الإعلانات

### الشكل
- فيديو عمودي ٩:١٦، **٣٠ ثانية**، النسخة النظيفة بدون علامة تيك توك.
- الترجمة العربية محروقة على الفيديو.
- الدعوة بالفيديو نسخة الإعلان: "اضغط الزر تحت وكلمنا واتساب".

### النص الأساسي (Primary text): قالب
```
{هوك الفيديو كسطر أول}
{جملة الفايدة من الجزء ٣}
👇 كلمنا واتساب ونفحص لك إعلان شقتك مجاناً.
```

### مثال جاهز (فيديو ١: حجز)
- **النص الأساسي:**
  شقتك على جاذر إن وما تنحجز؟
  أغلب الإعلانات اللي نفحصها فيها ٣ أخطاء تتكرر: الغلاف، العنوان، وسرعة الرد.
  👇 كلمنا واتساب ونفحص لك إعلان شقتك مجاناً.
- **العنوان (Headline):** فحص مجاني لإعلان شقتك
- **الوصف:** سويتي · إدارة شقق الإيجار اليومي بالرياض
- **الزر:** Send WhatsApp message (أرسل رسالة واتساب)

### رسالة الترحيب بالواتساب (Message template)
- **الترحيب:** هلا 👋 حياك الله في سويتي. وش تحب نساعدك فيه؟
- **أسئلة جاهزة (Ice breakers):**
  1. أبي فحص مجاني لإعلان شقتي
  2. كم تاخذون على إدارة الشقة؟
  3. شقتي على منصة وحدة، أبي أوسعها
  4. أبي أكلم أحد

### الإعلانات لكل فيديو (تتعبى بعد النشر العضوي)

| الإعلان | الفيديو | الهوك | Post ID (إنستقرام) | الكلمة |
|---|---|---|---|---|
| `V?\|HA\|…` | أفضل فيديو ١ | A | | |
| `V?\|HB\|…` | أفضل فيديو ١ | B | | |
| `V?\|HC\|…` | أفضل فيديو ١ | C | | |
| … | أفضل فيديو ٢ | A/B/C | | |
| … | أفضل فيديو ٣ | A/B/C | | |

## ٧. التتبع

- كل محادثة واتساب من إعلان تنسجّل بسجل العملاء: **اسم الإعلان + الحي + هل هو مالك مؤهل**.
- المالك المؤهل = عنده شقة إيجار يومي (أو بيجهز وحدة) بالرياض، وتم التواصل معه.
- روابط الموقع (إذا استخدمناها) بـ UTM:
  `?utm_source=meta&utm_medium=paid&utm_campaign={{campaign.name}}&utm_content={{ad.name}}`

## ٨. القواعد التلقائية (Automated rules)

| القاعدة | الشرط | الإجراء | الفحص |
|---|---|---|---|
| وقف الإعلان الضعيف | صرف ≥ ١٥٠ ريال **و** محادثات = ٠ | إيقاف الإعلان + إشعار | يومي |
| وقف التكلفة العالية | صرف ≥ ١٥٠ ريال **و** تكلفة المحادثة > ٢× الهدف | إيقاف الإعلان + إشعار | يومي |
| الهوك الضعيف | ظهور ≥ ٢٬٠٠٠ **و** نسبة أول ٣ ثواني < ٢٥٪ | إشعار فقط (نغير الهوك يدوياً) | يومي |
| التوسع | تكلفة المحادثة ≤ الهدف لـ٣ أيام | إشعار (الزيادة ٢٠٪ يدوية بعد الموافقة) | كل ٤٨ ساعة |
| تعب الإعلان | التكرار > ٣ (إعادة الاستهداف) | إشعار | يومي |

> تكلفة المحادثة المستهدفة: **تنحدد بعد الأسبوع الثاني** من أرقام حقيقية. لين ذاك الوقت القواعد تشتغل كإشعار فقط، مو إيقاف.

## ٩. ترتيب التنفيذ للجلسة المحلية

1. اقرأ هذا الملف و`campaigns.json`.
2. افحص الحساب: العملة، التوقيت، الصفحة، الإنستقرام، الواتساب، البكسل. اعرض النتيجة.
3. ابنِ الجماهير المخصصة (القسم ٤).
4. ابنِ نموذج العملاء (القسم ٦).
5. ابنِ الحملات الثلاث **PAUSED** بدون إعلانات، واعرض الملخص.
6. بعد ما خالد يحدد أفضل ٣ فيديوهات: أضف الإعلانات التسعة بالـ Post IDs، **PAUSED**.
7. انتظر "شغّلها" قبل تفعيل أي شي.
8. كل يومين: تقرير قصير (الصرف، المحادثات، التكلفة، أفضل وأسوأ إعلان) واحفظه بـ Obsidian.
