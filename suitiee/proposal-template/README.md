# قالب عرض تشغيل سويتي

عرض للملاك من 7 صفحات (16:9)، كل صفحة إطار HTML بنفس تخطيط العرض المرجعي، لكن بهوية سويتي: خلفية بيضاء، الحبر `#16130F`، اللون المميز الطوبي `#A8481B`، خط IBM Plex Sans Arabic وخط Inter، والشعار Suit**i**ee.

| # | الصفحة |
|---|---|
| 1 | الغلاف: الشعار |
| 2 | عن سويتي: نمط البلاطات والنص |
| 3 | نهجنا: استثمر ← جهّز ← شغّل واربح |
| 4 | سويتي بالأرقام |
| 5 | العقار: صورة الخريطة وصورة الواجهة والتفاصيل |
| 6 | الدراسة المالية: ثلاث سيناريوهات تُحسب تلقائيًا |
| 7 | الختام: الشعار والتواصل والسجل التجاري |

## الاستخدام
1. افتح `suitiee-proposal.html` وعدّل كتلة `proposal` (JSON) في أعلى الملف. كل نصوص الصفحات موجودة فيها.
   - أي قيمة تبدأ بـ `[` تظهر مظللة على أنها خانة تنتظر التعبئة.
   - `finance.units`: عدد الوحدات، وسعر الليلة، ونسبة الإشغال لكل سيناريو.
   - `finance.costs`: نسب التكاليف من الإيراد لكل سيناريو.
   - `property.mapImage` و`property.photo`: مسار صورة بجانب الملف.
2. لإخراج PDF: من Chrome اختر طباعة ← حفظ PDF، أو شغّل:
   `node render.js suitiee-proposal.html out.pdf [png_dir]`

`suitiee-proposal-sample.pdf` نسخة مثال، وأرقامها نفس أرقام الدراسة المرجعية (8 استوديوهات و7 شقق غرفة وصالة).
الإحصائيات وأرقام التواصل والسجل التجاري خانات فارغة، فعبّها بأرقام حقيقية قبل الإرسال.
