# قالب عرض تشغيل سويتي

عرض للملاك من 7 صفحات (16:9). كل صفحة إطار HTML بنفس تخطيط العرض المرجعي، وبهوية سويتي الرسمية المأخوذة من suitiee.com:

- **الشعار:** الباب النحاسي مع النجمة الذهبية (`assets/logo/`)
- **الخط:** ثمانية Thmanyah Sans (`assets/fonts/`)
- **الألوان:** حبر `#2B1D14`، نحاسي `#C2703D`، ذهبي `#E0A33D`، كريمي `#FCF7EF`، رملي `#F0E6D9`
- **العنصر البصري:** نمط الأبواب المأخوذ من الشعار، والصور داخل إطار مقوّس

| # | الصفحة |
|---|---|
| 1 | الغلاف: صورة داخل باب مقوّس، الشعار، المالك والعقار والتاريخ |
| 2 | عن سويتي: نمط الأبواب، النص، الخدمات |
| 3 | نهجنا: استثمر ← جهّز ← شغّل واربح |
| 4 | سويتي بالأرقام |
| 5 | العقار: صورة الخريطة وصورة الواجهة والتفاصيل |
| 6 | الدراسة المالية: ثلاث سيناريوهات تنحسب تلقائيًا |
| 7 | الختام والتواصل |

## الملفات الجاهزة
- `suitiee-proposal.pdf`: للإرسال المباشر.
- `suitiee-proposal.pptx`: للتعديل في PowerPoint.
  - كل النصوص قابلة للتعديل، والدراسة المالية جدول حقيقي.
  - **لتغيير أي صورة:** زر الفأرة الأيمن على الصورة ← «تغيير الصورة». الإطار المقوّس أو المدوّر يبقى كما هو.
  - **ثبّت الخطوط أولًا** من `assets/fonts/*.otf`، وإلا يستبدلها PowerPoint بخط آخر.

## التعديل من المصدر
1. افتح `suitiee-proposal.html` وعدّل كتلة `proposal` (JSON) في أعلى الملف.
   - أي قيمة تبدأ بـ `[` تظهر مظللة على أنها خانة تنتظر التعبئة.
   - الصور: `cover.photo` و`stats.background` و`property.photo` و`property.mapImage`.
   - `finance.units` و`finance.costs`: الأسعار والإشغال ونسب التكاليف لكل سيناريو.
2. أعد الإخراج:
   ```
   npm install            # مرة وحدة
   node render.js         # PDF (+ صور معاينة: node render.js suitiee-proposal.html out.pdf png/)
   node export-pptx.js    # PowerPoint
   ```

الصور الحالية أمثلة من موقع سويتي، وأرقام الدراسة المالية نفس أرقام الدراسة المرجعية. الإحصائيات ورقم الجوال والسجل التجاري خانات فارغة، فعبّها بأرقام حقيقية قبل الإرسال.
